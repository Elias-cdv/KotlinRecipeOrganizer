# Overview

As a software engineer expanding my skill set into modern JVM languages, I developed this project to explore Kotlin's expressive syntax, strong safety features, and functional programming capabilities. Building a structured backend command-line tool allows me to strengthen my software architecture principles while mastering new language paradigms.

The software is a **Kotlin Recipe Organizer**, a console-based application designed to manage, categorize, search, and analyze cooking recipes. It provides an interactive interface where users can store detailed recipe objects, filter recipes dynamically by category, calculate cumulative prep/cook times, and view aggregate statistics for their collection.

My purpose for writing this software was to gain practical, hands-on experience with Kotlin-specific features, including data classes, immutability patterns, null safety mechanisms (safe call and Elvis operators), collection operations, and control structures like `when` expressions.

# Development Environment

To develop and execute this software, I used the following tools and environment:

- **IDE:** IntelliJ IDEA Community Edition
- **JDK / Runtime:** OpenJDK 17
- **Version Control:** Git & GitHub

The project was written using **Kotlin** (version 1.9+). It relies on the Kotlin Standard Library, leveraging built-in collection tools (`List`, `MutableList`, `filter`, `map`, `average`) and standard console I/O handling.
